## 已确认的项目定位

项目暂名“企业文档问答知识库 Agent”，面向求职、实习和作品展示，以国内差旅与报销作为首版业务场景。

普通员工在有权限的知识库内查询制度，获得带依据的办理指南；系统结合管理员维护的模拟员工资料与本次出差条件，提供适用规则建议，估算住宿费和一种按天补贴。缺少必要条件时主动澄清，证据不足或冲突无法判定时明确说明。

实现必须包含 RAG，支持授权范围内有限补查。费用规则由管理员依据制度录入并关联原文，系统按明确公式计算。

## 已确认的角色与职责

| 角色 | 已确认职责 | 待细化 |
| --- | --- | --- |
| 管理员 | 维护知识库、文档、模拟员工资料和费用规则 | 用户创建方式、授权操作、具体页面与操作校验 |
| 员工 | 查询被授权知识库，获得指南和费用估算，管理个人会话历史 | 知识库选择方式、条件修正、历史引用与权限变化处理 |

首版为单企业、多用户，按知识库授权。

## 已确认的首版功能范围

以下功能全部属于已确认的首版交付范围，不能因实施顺序调整而自动移出范围。

| 模块 | 已确认内容 | 主要待细化事项 |
| --- | --- | --- |
| 用户与权限 | 管理员、员工；按知识库授权 | 登录交互、授权矩阵、原文访问与历史权限 |
| 员工资料 | 管理员维护模拟资料，登录后自动带入 | 属性字段、可见性、资料与本次条件的优先关系 |
| 知识库与文档 | 上传、处理状态、失败重试、替换、删除；有效且成功处理的资料参与问答 | 状态转换、替换时点、删除后历史引用 |
| 文档格式 | Markdown、文字型 PDF、Word DOCX | 复杂排版边界、大小限制、引用定位 |
| RAG 问答 | 关键词与向量混合检索，依据文档生成答案，来源可追溯 | 分段、中文分词、融合、引用检查及模型型号 |
| 跨文档指南 | 综合多份资料整理办理流程 | 答案结构、完整性检查、冲突提示 |
| 条件建议 | 利用员工资料和用户提供的本次条件，澄清必要信息并给出适用规则 | 条件字段、修正、缺失及冲突行为 |
| 费用估算 | 按已确认矩阵估算住宿标准预算与80元/天补贴；人工录入关联制度；更新暂停受影响规则 | 金额格式、事务与激活校验 |
| 受控补查 | LangChain Agent；每轮5次检索、10次对话请求、90秒，重试计入次数，到限停止 | 工具契约、具体错误重试和状态反馈 |
| 会话历史 | 多轮对话；个人会话新建、重命名、删除 | 历史引用、条件变更、上下文长度 |
| 质量验证 | 40例：问答20、计算8、权限6、一致性4、限额2；确定性全过，问答至少18/20，严重错误修复 | 题目素材冻结、实测响应时间与费用 |
| 演示运行 | 本机程序与浏览器界面，调用外部模型 API | 启动、配置、依赖与运行说明 |

已确认的引用能力包括引用片段、可靠位置锚点及授权下载原文件；PDF 提供可验证页码，Word/Markdown 提供章节或段落位置。

## 已确认的初步技术方向

- Python FastAPI + Vue 前后端分离。
- PostgreSQL + pgvector 保存业务与向量数据。
- 百炼对话与文本向量 API。
- 关键词与向量混合检索。
- LangChain Agent 组织受控工具调用。

具体模型、版本、分词、融合、认证和任务执行方式仍待确认。此前较轻路线的推荐不替代上述用户明确选择。

## 建议的实施优先级与顺序

状态：**建议方案**。P0 表示首版必须覆盖的已确认能力；内部顺序仍可调整。

| 顺序建议 | 功能组 | 该阶段可检查的结果 |
| --- | --- | --- |
| P0-1 | 账号、知识库授权、模拟员工、制度与规则样本 | 不同员工身份和知识库范围可被验证 |
| P0-2 | 文档上传、处理反馈、基础生命周期及原文锚点 | 能找到来源；失败、替换和删除有明确反馈 |
| P0-3 | RAG 基础问答与跨文档指南 | 正常、无依据、冲突、越权问题有可核对结果 |
| P0-4 | 条件澄清、规则匹配和两类费用计算 | 计算输入、规则、明细和依据可复核 |
| P0-5 | 受控补查、个人会话历史与完整交互 | 复杂问题与持续对话可完成，调用能够停止 |
| P0-6 | 固定测试回归、费用记录、运行说明和演示准备 | 能复现主要流程并解释结果与限制 |

测试用例建议随各阶段逐步形成，在最终演示前统一回归，不集中留到最后编写。
