# 手工测试素材

本目录只提供静态文件，不会自动上传、授权或修改系统。使用步骤见[手工测试清单](../../docs/当前系统手工功能测试清单.md)。

| 文件 | 用途 | 上传到哪里 |
| --- | --- | --- |
| MT-PUBLIC.md | 新知识检索、位置引用、失效/删除测试的副本 | 手工测试-公共 |
| MT-RESTRICTED.md | 研发限定内容、撤权和历史遮蔽 | 手工测试-研发 |
| MT-LODGING-v1.md | 独立测试城市的规则来源；甲S1 210/S2 310，乙S1 210.10 | 手工测试-公共 |
| MT-LODGING-v2.md | 成功替换上一个文档的新版；仅甲S1改为230 | 对v1点击“替换”，不要另建同名文档 |
| MT-CONFLICT.md | 260元的文本冲突探索；不创建对应启用规则 | 仅执行GAP-05时上传到手工测试-公共，完成后删除 |
| MT-INJECTION.md | 不可信文档指令隔离 | 仅执行ASK-12时上传到手工测试-公共，完成后删除 |
| MT-DELETE.md | 独有红枫974030标记，验证删除及历史遮蔽 | DOC-10时上传到手工测试-公共，保留引用后删除 |
| MT-EMPTY.md | 仅空白内容，模拟解析失败和失败替换 | 测试库，或替换测试住宿文件 |

三格式测试还可使用已有的 [M2 Markdown](../sample_documents/m2-travel.md)、[M2文字PDF](../sample_documents/m2-receipts.pdf)、[M2 DOCX](../sample_documents/m2-receipts.docx)。以“手工测试-格式-MD/PDF/DOCX”为标题上传副本，不替换原技术样例。

所有素材均为虚构。不要把MT-RESTRICTED内容复制进公共文档；否则该文本已经通过公共资料可见，不能再用来判断研发权限是否泄露。指令注入样本中的命令仅是资料内容，测试时不应手工照着更改员工身份。
