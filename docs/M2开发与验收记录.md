# M2 文档、索引与检索交付记录

日期：2026-11-03（Asia/Shanghai）。用户明确表示已配置百炼 API Key，并授权执行 M2。以下记录实际实现与验证；未将工程默认值改写为用户单独确认的需求。

## 当前交付

- 管理员上传 MD、文字 PDF、DOCX；文件名与格式检查、10,000,000 字节文件上限、100 页 PDF、10 万提取字符、30 份未删除逻辑文档上限。
- 上传返回 202 和 document_id/version_id/job_id；持久任务排队、处理中、完成、失败，支持失败重试。页面自动轮询活动任务，显示可操作的失败原因。
- 本机单个后台 worker，通过 PostgreSQL 会话 advisory lock 避免多进程重复消费。重启将中断的 processing 任务标记为失败，可手动重试；queued 任务继续处理。
- 文件以随机内部标识存储，数据库保留原文件名、SHA-256、字节数、版本和有效期；上传路径不采用原文件名。
- Markdown 保存标题路径、真实行范围；DOCX 保存段落或表格/行号；PDF 保存实际页码与表格行。简单表格保留列标题与数据行关系，扫描页明确失败，不使用 OCR。
- 文本按段落、页面、表格行切片，每片最多 800 字符、长块重叠 120 字符。标题和纯表头不单独占用检索候选；标题上下文加入向量输入，原文与位置分开保存。
- 真实百炼 `text-embedding-v4` / 1024 维；每批最多 10 条、单次网络超时 25 秒、验证数量/维度/有限数值/非零向量，不自动改成假向量或静默降级。
- PostgreSQL `simple` 全文检索 + jieba 中文分词，GIN 索引；pgvector 余弦精确检索；两路各最多 20 条，RRF 合并去重后返回最多 6 条，显示命中分支。
- 员工在授权知识库内检索，打开原文来源抽屉、下载当前有效版本。管理员可核对片段、替换和删除文档。
- 替换版本只有解析与全部向量化成功后才原子发布；失败保留当前版本。引用接口仅返回当前有效、未删除、已授权来源。旧版本员工下载关闭，管理员仍可核对未删除文档的版本。
- 新增向量调用用量记录：调用前原子预留估算成本，80 元提醒、100 元阻断新请求；成功按服务返回 Token 修正估算，失败/超时保留预留并标记 unknown，不伪造零费用。

## 数据与配置

Alembic `0002_m2` 新建 documents、document_versions、document_chunks、ingestion_jobs、usage_records 五表；加上 M1 六表共十一张业务表。向量字段为 VECTOR(1024)，迁移与 ORM 一致性纳入测试。既有账号与授权保留。

模型空间指纹由 endpoint、型号、维度、embedding_revision 构成，查询只读取当前匹配的索引。当前型号和维度经真实输出验证后固定；更换时必须显式迁移/重建，不能混用向量空间。embedding_revision 可用于显式区分索引配置。

本机 `.env` 读取 DASHSCOPE_API_KEY、DASHSCOPE_BASE_URL、EMBEDDING_MODEL、EMBEDDING_DIMENSIONS；Key 不返回前端、日志或报告。CHAT_MODEL 目前仍是配置值，M2 没有调用对话模型，也没有冻结 Qwen/DeepSeek 最终选型。

MODEL_TESTS_ENABLED 是历史评测预留字段，不是 M2 业务调用总开关。正常上传与检索按用户操作调用向量服务；显式联网冒烟脚本必须提供 `--live`。普通后端测试主动清空真实模型 Key，使用假接口与独立数据库。

## 新接口

以下路径均以 `/api/v1` 为前缀，认证沿用 M1。

| 方法和路径 | 输入与行为 |
| --- | --- |
| GET /knowledge-bases/{kb_id}/documents | 员工仅当前有效文档；管理员含最新任务和失败状态 |
| POST /admin/knowledge-bases/{kb_id}/documents | multipart：file、title、可选 effective_from/effective_until，返回 202 |
| POST /admin/documents/{id}/versions | file、expected_current_version_id、可选有效期；处理成功后替换 |
| DELETE /admin/documents/{id} | 204，逻辑删除并立即阻断后续检索/引用/下载 |
| GET /admin/ingestion-jobs/{id} | 状态、attempt_no、错误码及安全错误说明 |
| POST /admin/ingestion-jobs/{id}/retry | 仅最新失败任务可重试，202；活动任务或过期版本 409 |
| GET /admin/document-versions/{id}/chunks | 原文片段及位置，供管理员核对 |
| POST /search | JSON：query（1—300字符）、kb_ids（1—30个UUID），返回片段、来源、位置和排序分支 |
| GET /document-chunks/{id} | 再次核验权限、文档状态、当前版本、有效期与索引空间 |
| GET /documents/{id}/versions/{version_id}/download | Bearer 鉴权后附件下载，员工只下载当前有效版本 |
| GET /admin/usage | 本应用向量请求数、累计估算、提醒/暂停状态；不返回密钥 |

日期必须包含时区；失效时间为不包含的上界。替换发布立即切换当前版本，旧版不自动回退；未来生效的新版本发布后，文档会暂不可检索，直到该版本生效。当前不实现定时切换未来版本。

## 本机体验

打开 `http://127.0.0.1:5173/knowledge`。管理员可通过侧栏“文档检索”或知识库管理的“文档”入口上传与管理；员工仅见授权库和有效文档。

已在公共库放入三份明确标记为“技术样例”的 MD/DOCX/PDF，源文件在 `data/sample_documents/`。这些用于验证解析和检索，不代表完整示范制度已冻结，也不能当作正式报销制度。

可尝试“北京住宿标准”“出差报销需要什么材料”，查看来源抽屉并下载。M2 展示原文证据，不生成 AI 回答。会话、Agent、费用规则与计算仍属于 M3/M4；历史回答遮蔽和规则暂停闭环随相应模块实现。

```powershell

.venv/Scripts/python.exe -m app.cli migrate

```

原 start_m1.ps1/stop_m1.ps1 保留为兼容入口，当前启动 M2。Docker Desktop 需运行，数据库容器维持原端口和卷。

## 实测与验收

- 首次配置预检：1 次真实请求、2 条短文本，均返回 1024 维向量，12 个输入 Token。报告 `.m2/embedding-probe.json`；发生在用量表启用前，未混入表内统计。
- 真实链路：三格式上传→后台解析→向量化→原子发布；两条问题均检索到预期证据，来源与鉴权下载通过。最终样例各 4/3/1 个片段。报告 `.m2/live-smoke.json`，初始报告另留存。
- 后端：30 项通过，包含原 M1 19 项与 M2 11 项；验证三格式/位置、限制、混合检索、撤权、替换/删除、失败重试、日期、向量维度、预算、外部调用期间撤权/禁用后的再次鉴权、重启中断恢复。报告 `.m2/backend-results.xml`。
- 浏览器：6 条通过，包含 M1 四条回归，以及 M2 管理端上传/核对/替换失败/重试/发布/删除、员工真实检索/来源/鉴权下载/390px显示。浏览器产生少量真实向量请求，临时文档结束后逻辑删除。报告 `.m2/browser-results.json`，截图 `.m2/search-desktop.png`、`.m2/search-mobile.png`。
- 前端类型检查与生产构建、后端 Ruff 均通过。固定 40 例完整业务验收及对话模型 10 例对照未执行；不将当前片段检索通过写成 AI 问答准确率通过。

## 可复现命令与边界

```powershell
Push-Location backend
.venv/Scripts/python.exe -m pytest tests -q
Pop-Location
Push-Location frontend
npm.cmd run build
# 此命令包含真实向量调用，需服务与默认样例就绪
npm.cmd run test:e2e
Pop-Location
# 显式联网；已有就绪样例默认复用，仅执行两条检索
backend/.venv/Scripts/python.exe scripts/m2_live_smoke.py --live
```

`--live --reindex` 仅替换三份脚本命名的技术样例并重跑检索，会产生额外向量用量。脚本不更改密钥、不测试聊天模型。

当前成本估算固定使用北京地域 text-embedding-v4 原价 0.5 元/百万输入 Token，按 UTF-8 字节数保守预留，再按服务返回用量修正；记录金额不是实际扣款。不同地域/价格变动需同步核对费率，失败和在途请求有估算不确定性。本次模型调用仅向量：用量表记录16次、574个输入Token；表启用前预检另1次、12个输入Token。合计586个输入Token，按上述单价估算0.000293元，实际以百炼账单为准。最终汇总见`.m2/final-summary.json`。[官方向量接口](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)、[官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)。

当前文件采用逻辑删除，原文件和历史元数据保留，物理清理策略尚未实现。解析器支持正文与简单表格，不保证复杂合并单元格、嵌套表格、图片文字或复杂排版还原。单 worker 适合本机演示；独立任务服务、生产监控和故障自动切换不是本阶段交付。检索按排名返回相近片段，不承诺每次都有相关答案，排序分数不是正确概率。
