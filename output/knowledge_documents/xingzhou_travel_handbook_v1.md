# 企业差旅与费用报销管理手册

星舟科技有限公司  虚构企业示例

文档编号：XT-TRV-2026-01；版本：1.0；示例生效日期：2026-11-19。

虚构企业示例，仅用于知识库测试与作品展示；全部流程与时限均为模拟设定，不代表真实企业制度。

## 一 适用范围与职责

本手册供员工查询国内差旅的申请流程、住宿与补贴标准、报销材料和异常处理方法。员工应先确认行程与本人职级，再核对标准并保留费用依据。所有审批、票据审核和付款由企业既有人工流程完成。

### 第1条 制度范围

本手册适用于星舟科技有限公司S1、S2职级员工的国内公务出差，不适用于海外差旅、长期驻场、搬迁安置及个人旅游。因业务需要超出适用范围时，应事前联系直属负责人、行政部和财务部另行确认，不得直接套用本手册的城市或补贴标准。

现阶段知识问答系统支持单次、单目的地、1至30个整数出差天数，以及0至29个整数住宿晚数且晚数小于天数的标准预算。更长行程、多目的地和复杂日期计算须转人工处理；这属于软件支持边界，不表示企业一律禁止相关行程。

### 第2条 员工资料与基本口径

姓名、部门和职级以管理员维护的员工资料为准。员工发现资料有误，应联系管理员修正后重新确认预算，不能通过对话自称S2改变适用标准。出差天数和住宿晚数必须分别核对，不得看到“三天”便默认“两晚”。

“标准预算”是按适用住宿标准乘晚数，再加日补贴乘天数得到的两项额度；“实际报销”是财务依据有效材料及审批结果确认的金额。标准预算不包含交通费等其他费用，也不等于财务承诺的最终报销金额。

### 第3条 各方职责

| 责任方 | 主要职责 |
| --- | --- |
| 出差员工 | 确认目的、行程和数量；提出申请；保存凭证；按期提交材料并说明例外事项。 |
| 直属负责人 | 确认业务必要性、人员安排与时间；批准或退回申请；审核业务真实性。 |
| 行政部 | 维护通用流程说明，协助住宿安排与异常沟通，不代替财务确认票据和付款。 |
| 财务部 | 核对材料、适用标准及审批依据，反馈补充项，按审批结果安排付款。 |
| 知识库管理员 | 维护员工资料、文档权限和版本；核对费用规则来源；处理来源更新后的恢复。 |

研发等部门的附加要求应查阅本人获授权的专门制度。本手册不收录受限项目内容，不得将研发限定资料复制到公共知识库以规避权限。

## 二 出差申请与行程管理

### 第4条 出发前申请

员工应在计划出发前至少3个工作日，通过企业既有协同渠道提交出差申请。申请内容包括业务目的、目的地、出发和返回日期、出差天数、住宿晚数、同行人员、费用承担部门及预计费用。涉及项目时填写合法获授权的项目归属，不在公共知识库上传项目敏感正文。

员工先核对本人职级和城市标准，提交直属负责人确认业务必要性。存在超标准住宿、特殊交通安排或其他例外时，应同时说明理由并交财务核对。获得明确批准后再安排需要企业承担的预订；知识助手生成的指南或预算不能替代批准记录。

### 第5条 紧急出差

临时紧急出差无法满足3个工作日提前量时，员工应先取得直属负责人可留存的明确批准，并在出发后1个工作日内补齐申请材料，说明紧急原因和实际行程。紧急情形不自动放宽住宿标准，也不使缺少依据的费用当然获得报销。

### 第6条 条件确认与行程变更

在知识助手中输入“北京3天2晚”等条件后，应核对待确认卡上的目的地、天数和晚数，再点击确认计算。缺少晚数、城市不明确或数量相互矛盾时应先补充。只询问每晚住宿标准时，不需要额外填写无关的天数和晚数。

目的地、出差天数或住宿晚数发生变化，应先向直属负责人说明业务影响，补充原申请的变更记录；在知识助手中修正条件并重新确认预算。原北京预算不能直接当作杭州的新预算，已保存的旧结果也不会自动变成新标准。

私人延住、绕行及非公务活动应与公务部分区分。员工应保存公务行程与私人安排的边界说明，财务按实际批准内容处理；不得把私人增加的晚数直接并入公司标准预算。

### 第7条 取消与预订损失

行程取消后应及时通知负责人并办理退订，保存订单、取消时间、退费和手续费凭证。因业务原因产生的合理损失提交人工审核；员工不得仅凭系统仍保留一张预算卡就报销已经取消的行程。知识系统不执行订票、退订、审批或付款操作。

本手册中的工作日以企业公布的工作日历为准。系统不根据本手册自动计算法定节假日或承诺某个具体到账日期。

## 三 住宿补贴与预算标准

### 第8条 城市与每晚住宿标准

| 城市类别 | 城市名单 | S1每晚标准 | S2每晚标准 |
| --- | --- | --- | --- |
| 甲类 | 北京、上海 | 300元/晚 | 500元/晚 |
| 乙类 | 杭州、南京 | 200元/晚 | 350元/晚 |

城市名单采用明确名称匹配，未列明的广州等城市不自动归入甲类或乙类，也不按省份、城市规模或相邻城市类推。城市名称或别名未约定时先请管理员核对；系统不能为“北京市”等输入擅自增加名称映射。

住宿标准预算等于本人适用的每晚标准乘已确认住宿晚数。零晚住宿预算为零，但目的地仍须有适用住宿标准。合住时不得凭同一张住宿凭证重复报销同一笔费用；实际分摊和超标准例外均由财务人工核对。

### 第9条 每日补贴

国内差旅补贴统一为80元/天，S1和S2相同，当前不按城市类别区分。补贴计费数量使用员工确认的出差天数，不能把住宿晚数当作天数。补贴采用本示例制度统一口径，不自行增加餐补、交通补贴或其他未定义的单价。

### 第10条 标准预算计算

住宿预算额度＝每晚住宿标准×已确认住宿晚数。出差补贴＝80元/天×已确认出差天数。两项标准预算合计＝住宿预算额度＋出差补贴。金额按人民币两位小数展示，由程序用十进制计算并四舍五入到分。

| 已确认条件 | 住宿预算 | 出差补贴 | 两项合计 |
| --- | --- | --- | --- |
| S1 北京 3天2晚 | 600.00元 | 240.00元 | 840.00元 |
| S2 北京 3天2晚 | 1000.00元 | 240.00元 | 1240.00元 |
| S1 杭州 3天2晚 | 400.00元 | 240.00元 | 640.00元 |
| S2 南京 2天1晚 | 350.00元 | 160.00元 | 510.00元 |
| S1 上海 1天0晚 | 0.00元 | 80.00元 | 80.00元 |

### 第11条 完整合计与实际支出

只有必要条件已确认、住宿与补贴规则均有效且可访问时，系统才能给完整合计。未知城市、缺少晚数、规则暂停、依据失效或规则冲突时，应说明缺失项；可以展示有有效依据的单项，不能用零元假装缺失费用已核清。

实际住宿原则上按有效凭证金额与批准住宿额度中的较低值核对，获事先批准的例外由财务另行处理。例如S1北京2晚标准额度600元，实际凭证540元时不能仅凭标准预算要求报销600元。该实际支出核验不由现阶段知识系统自动完成。

## 四 报销材料与人工审核

### 第12条 材料提交期限

员工应在返回后10个工作日内，通过企业既有报销渠道提交完整材料。逾期应说明原因，交直属负责人及财务确认处理方式；本示例不规定逾期一律作废，也不允许助手自行承诺一定报销。以下材料用于外部人工流程，不要求把个人票据上传到知识库。

| 材料类别 | 应包含的内容 |
| --- | --- |
| 出差与变更记录 | 已批准申请、实际行程、必要的变更或紧急出差说明，能够对应业务目的与费用承担部门。 |
| 住宿材料 | 住宿凭证、入住与离店信息、费用明细及支付记录，足以核对实际晚数和是否重复报销。 |
| 交通材料 | 车票或行程凭证、实际乘坐信息、订单与支付记录；退改签另附原因和损失凭证。 |
| 其他公务费用 | 项目用途、经办说明、批准依据及有效凭证；本手册没有定义单价的项目由人工核对。 |
| 报销汇总 | 按住宿、交通、补贴及其他类别分别汇总，列明预付或企业已支付部分，避免重复领取。 |

### 第13条 交通与其他费用边界

本示例中，S1和S2员工通常选择高铁二等座或民航经济舱；特殊安排应在申请中说明并取得批准。市内交通应能对应公务行程；自驾、里程补贴及其他特殊支出需另行确认，本手册未设定可自动计算的单价。

交通费、退改签费、会务费和其他公务费用不包含在第三章的住宿加日补贴合计内。即使员工在聊天中提供机票金额，也不能据此声称系统已经生成包含所有支出的完整报销额。

### 第14条 审核与付款节点

财务收到完整材料后，通常在2个工作日内反馈材料是否齐全。直属负责人或项目负责人通常在材料完整后3个工作日内完成业务确认。发现缺项、重复记录、行程不一致或超标准未批准时，应明确退回原因和需补材料。

员工补齐后重新提交，处理时限从完整材料重新收齐时计算。全部审批完成后，财务通常在5个工作日内安排付款；该时限是虚构流程目标，具体到账受结算批次及收款信息影响。知识助手不能查询或保证某笔报销的审批进度与到账时间。

### 第15条 退回与重复报销

被退回的申请应按原因补充或更正，不新建另一笔申请绕过原记录。已由企业直接支付、已预付或已报销的同一笔费用不得重复领取。票据遗失、信息错误或无法证明公务用途时，员工应说明情况，交人工审核，不以助手给出的预算代替凭证。

## 五 异常处理与知识库使用

### 第16条 制度版本与冲突

员工查询时应核对来源标题、版本、条款位置及有效性。知识系统只解释当前有效制度，不按历史出差日期自动匹配旧标准。两份当前材料互相矛盾且没有明确优先依据时，应列出可访问的冲突条款并联系管理员，不以“上传得晚”直接确定适用金额。

制度更新、删除、到期或授权撤销后，原依据可能不可访问；受影响费用规则须由管理员核对当前条款、单价、城市和职级后逐条恢复。旧回答或预算可能显示依据不可用，旧金额不会自动更新。重新启用知识库也不等于自动恢复全部暂停规则。

### 第17条 资料权限与问题反馈

员工仅在获授权知识库中检索、引用和下载资料。管理员管理账号、制度和规则，不因此获得浏览他人私人会话的权限。个人证件、银行卡号、完整票据和真实项目资料不作为本示例的公共测试素材。

发现错误回答时，保留问题原文、账号职级、目的地与数量、引用条款、发生时间及截图，提交管理员核对。反馈应隐藏密码、API Key、Cookie和完整访问令牌；不要先删除问题现场或反复追问挑选一次正确答案作为处理结果。

### 第18条 常见问题

问：北京出差三天，能自动按两晚算吗？答：不能。必须补充或确认实际住宿晚数；零晚也需要明确填写。问：我自述是S2，为什么仍按S1标准？答：适用职级来自管理员资料，应先纠正资料再重新确认预算。

问：广州可以按甲类城市标准吗？答：本手册未列广州，不能自动归类，应补充经核对的标准。问：一天不住宿还有补贴吗？答：在目的地有适用标准且规则有效时，1天0晚的住宿预算为0，日补贴为80元。

问：住宿标准300元，我实际住260元，能报300元吗？答：标准预算是额度，实际报销按凭证与批准额度核对，不能据预算当然领取差额。问：助手说预算840元，是审批通过了吗？答：该数值仅为住宿与补贴的标准估算，不是审批结果或所有支出的总额。

问：上传新制度后就会自动按新价格计算吗？答：上传只使资料具备检索条件，费用规则仍需管理员绑定来源并核对启用。问：为什么原来能看的回答现在隐藏了？答：可能发生来源更新、删除、失效、撤权或规则修订，应核对当前依据后重新提问或计算。
