## 结果与问题分类

- 通过：完成规定步骤，事实、权限、金额、引用和交互满足预期。
- 失败：已实际操作，至少一项明确预期不满足。
- 阻塞：系统打不开、前置失败、缺文件或需要技术协助，尚不能验证。
- 建议：体验改进或尚未确认的新范围，例如是否提供开放聊天。
- 未测：还没有执行。

缺陷类型可选：功能故障 / 金额或规则 / 权限或泄露 / 引用或编造 / 配置或数据 / 交互体验 / 待确认范围。  
建议严重度：S0为越权、错误金额、编造企业制度/错误引用等关键问题；S1为主要流程无法完成；S2为次要交互、文案或布局。最终优先级结合复现结果确定。
